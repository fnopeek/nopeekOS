# Archived comments

Every comment block of the Rust sources as of tag `comments-archive-2026-10`,
before the cleanup to `docs/spec/COMMENTS.md`. One file per source file,
each block with its line range and the code line it documents.

Line numbers refer to the tagged commit: `git show comments-archive-2026-10:<path>`.
Regenerate (from HEAD) with `python3 tools/comments.py archive <dir>`.
